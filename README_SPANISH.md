## Filosofía
Usas `rclone` porque te importan tus datos. Este proyecto le da mucho valor a eso y busca ofrecer una experiencia estable y agradable tanto a novatos como a veteranos.

Lo conseguimos con un conjunto de funciones bien elegido, en lugar de intentar hacerlo todo. Tras unos minutos usando la app, sabrás si es para ti.

...y si no lo es, echa un vistazo a [Rclone Cloud](https://github.com/rclone/rclone-cloud-beta), pensado para usuarios avanzados y organizaciones.
