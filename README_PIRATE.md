## Contribootin'
We been awaitin' yer arrival...

Some fine plunder t' tackle:
- Patch an open [**Issue**](https://github.com/rclone/rclone-ui/issues)
- Add yer own tongue t' th' translations ([no need t' clone th' repo](https://rclone.github.io/rclone-ui/))
- Spread th' word in every port, tell yer crew!

## Th' Pirate's Code
Ye sail with `rclone` 'cause ye guard yer treasure. This ship holds that dear, an' aims t' give landlubbers an' old salts alike a steady, merry voyage.

We manage it by stowin' a focused hold o' features, 'stead o' tryin' t' be a jack o' all trades. After but a few minutes aboard, ye'll know if she be th' ship fer ye.

...an' if she ain't, train yer spyglass on [Rclone Cloud](https://github.com/rclone/rclone-cloud-beta), built fer power users an' whole fleets.
