## 理念
你用 `rclone`，是因为你在乎自己的数据。这个项目非常看重这一点，力求让新手和老手都能获得稳定、愉快的体验。

为此，我们专注于一组精选的功能，而不是什么都想做。只要用上几分钟，你就会知道它适不适合你。

……如果不适合，可以看看 [Rclone Cloud](https://github.com/rclone/rclone-cloud-beta)，它面向高级用户和组织。
